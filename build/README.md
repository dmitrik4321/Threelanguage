# Python-билд десктоп-приложения (тестовый, без EXE)

Запуск: `python3 build/app.py` — нужен Python 3.10+ с tkinter (входит в стандартную сборку).
Pillow опционален: с ним показывается PNG-маскот дракона, без него — цветной круг-заглушка.

## Что это
Первый интерактивный билд по HANDOFF: один экран на tkinter, ядро НЕ дублируется —
импортируется из `shared/algorithm/reference.py` (этот же код гоняет golden-фикстуры CI):

| Фичера | Реализация |
|---|---|
| Placement-тест | адаптивный IRT (`placement_run`), мини-банк 12 вопросов level 1..6 |
| Урок-заглушка | «Как переводится Hi? → Привет/Пока/Корова», выбор + ввод, CJK partial_credit |
| SRS | FSRS-lite `next_state`, карточки живут в SQLite |
| АФК | темп-монитор ×10 медианы, idle>25с вычитается, сонный дракон при idle>90с |
| Оценка урока | 0..100 = 0.45·точность + 0.15·скорость + 0.20·стабильность + 0.20·усилие |
| Прогресс | минуты на каждый язык (en/pt-BR/zh) + дневные прогресс-бары; идут weight_ms, не wall-clock |
| Состояние | `~/.threelanguage/desktop.db` (SQLite), сброс: удалить файл |

## Файлы
- `app.py` — UI и связки (tkinter)
- `content.py` — данные-заглушки (урок + банк placement)
- `smoke_test.py` — автопрогон под Xvfb: placement→урок→АФК→итог→перезагрузка состояния

## Проверка
```
xvfb-run -a python3 build/smoke_test.py   # 12 проверок, SMOKE OK
./tools_ci.sh                             # паритет ядра всё ещё зелёный
```

## Ограничения тест-билда
Аудио/говорение — заглушки (kind есть, проигрывания нет); база уроков одна;
синхронизация с backend и .threelanguage-экспорт не подключены; локализация отложена.
