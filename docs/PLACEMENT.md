# Тест уровня (placement) — определение отправной точки (v0.1)

## Цель
При первом выборе языка — адаптивный тест (16–24 вопроса, ~5 мин), который сажает
пользователя на уровень A1..C2 (CEFR; HSK/JLPT/TOPIK-маппинг для CJK) и начальные
SRS-состояния карточек, чтобы знающий не долбил «apple».

## Механика (эталон: reference.py::placement_run)
- Вопросы размечены `level` 1..6 и `diag_score`; θ старт = 3.5, вопрос ближайший к θ.
- Обновление θ — 1PL IRT: `P=1/(1+e^-(θ-b))`, θ += η·(y−P), η=0.5.
- Стоп: SE(θ)<0.3 (и минимум 16 вопросов) или 24 вопроса.
- Тайт-брейкеры: два Again на лёгком → вниз; два Easy (score≥90) → вверх.
- Типы только CHOICE/LISTEN_CHOOSE (быстро; письмо измерим на реальном материале).

## Результат
- assigned_level = clamp(round(θ)) → стартовая колода.
- Пре-заполнение card_states для уровней ниже assigned: дальние S=30д, граничные S=7д
  (тест экономит повторения — сразу виден эффект).
- Профиль θ_per_skill (reading/listening/vocab) влияет на микс сессий.
- Пересдача не чаще 1/14 дней (анти-грефинг).

## Анти-чит
Рандом даёт θ≈середину, но ось consistency режет паттерны («всегда первый вариант») →
«тест не пройден, попробуй честно», уровень не назначается.
