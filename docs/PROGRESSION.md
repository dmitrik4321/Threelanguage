# Интенсивность, дневной бюджет, прогресс-бар (v0.1)

## Модель (по ТЗ: минуты на каждый язык, бар за день)
Настройки: `per_language_minutes{lang: 5..120, шаг 5}` (сумма ≤180), таймзона,
`day_start_hour=4:00` (учебный день, чтобы ночные занятия не рвали streak).

## Прогресс-бар дня (главный элемент хоума, live)
- Три сегмента = три головы/языка: filled = Σ effective_session_ms (АФК-weight!) / budget.
- Цвет: серый → зелёный (идёт) → золотой (бюджет закрыт) → красный-пульс (просрочено вчера).
- Кольцо вокруг дракона = % всех трёх бюджетов.
- Бюджет привязан к аккаунту, не к устройству: позанимался на телефоне → desktop покажет
  закрытый сегмент (event-log, LWW).

## Перебор/недобор
- Закрыл бюджет → продолжать можно, XP×0.5 + предупреждение «пережог» (v2: fatigue-модель).
- Недобор → вечерний push (Android) / трей-иконка (desktop): дракон hungry.
