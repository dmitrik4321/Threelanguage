# Оценка урока 0..100 — «чтобы не отвечал на отвали» (v0.1)

## Идеология
Оценка ставится за УРОК (сессия 10–25 заданий), не за карточку. Итог =
`round(100 × (0.45·A + 0.15·B + 0.20·C + 0.20·D))`, clamp [0..100]; пустой/прерванный урок → 0.

| Ось | Вес | Как считается | Против чего |
|---|---|---|---|
| A Accuracy | 0.45 | частичный кредит: точный=1, опечатка (Levenshtein≤1)=~0.85…, подсказка ×0.7 | угадайка |
| B Speed-vs-pace | 0.15 | ≤p75(kind)=1.0, линейно до 0 при ×3; «прострелил» быстрее p25 → ×0.5; AFK-исключённые выпадают | тянуть резину / кликать не глядя |
| C Consistency | 0.20 | 1 − норм. энтропия распределения качества ответов (n≥4) | спам «наугад» |
| D Effort | 0.20 | пропуск −0.8, переслушиваний >2 → −0.1/шт, самокоррекции +0.05 (до +0.15) | халтура |

## Анти-«на отвали» механики
1. Choice: 4 варианта, дистракторы морфологически близкие → рандом ≈25 баллов, ось C его режет.
2. Type: частичный кредит (см. reference.py::partial_credit, NFKC+diacritics) — 1 буква ≠ 0.
3. Связка с SRS: score<45 → грейдж Again всем карточкам урока, 45–69 → Hard. Халтурщик
   буквально удваивает себе будущую долбёжку. Кнут встроен в ядро.
4. Итог урока показывает реакцию маскота: ≥85 cheer, 60–84 idle, 45–59 sad, <45 angry.
