# Типы заданий и генератор сессий (v0.1)

## Два режима (по ТЗ)
- **Полноценный урок** (выбрал ≥30 мин/язык/день): Разминка 20% → Новый материал 40% →
  Отработка 30% → Смешанное повторение 10%; 20–25 заданий; тема/грамматика курса.
- **Микро-дуэль** (<30 мин): 5–10 заданий строго из due-очереди SRS, ≤3 новых карточек,
  чередование типов (не >2 одинаковых kind подряд). Экран «быстро на 5 минут».

## Банк типов (все три требуемых навыка + мои additions)

QUICK_RECALL — мой цепляющий бонус: сервер по расхождению «уверен vs попал»微调 desired_retention.

## Крючки вовлечения (нативно, без лутбоксов)
1. **Три головы = три языка**: streak языка питает свою голову; забросил → голова сонная/грустная,
   пропуск дня → дракон злой (маскот-эмоции из assets/mascot/).
2. Streak-страховка: одна заморозка/неделя, зарабатывается усердием (не покупается).
3. XP от оценки урока → «кладка»: инкубация нового цвета дракона (косметика, 6 образов).
4. Дневной бюджет-прогрессбар: три сегмента по языкам (PROGRESSION.md).
5. «Пламя долга»: due-просрочка > бюджета дней → мягкий дедлайн-таймер на хоуме.
6. Серия уроков ≥90 → режим берсерка: 3 дня XP×1.5.

## Генератор сессии (спека core/session, реализуют обе платформы)
```
queue = due_cards(lang) по возрастанию retention(now)   # худшая память primero
new_limit = micro: ≤3, full: 8–12
mix full: 60% recognition / 25% production / 15% listening-speaking
hard-cap: Σ weight_ms ≥ budget_min*60e3 (АФК-weight!) → конец сессии
```
