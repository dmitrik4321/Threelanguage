# Threelanguage

Приложение для изучения **трёх языков одновременно** (родной + два иностранных).
Маскот — трёхголовый пиксельный дракон: каждая голова — свой язык.
Девиз ядра: «общее ядро, два равноправных нативных клиента, без WebView».

Исторический ТЗ-документ первого дня сохранён как [`old_readme.md`](old_readme.md).

## Что уже работает

### Desktop-приложение (Python + tkinter)
Запуск из корня репозитория:
```bash
pip install pillow flask          # Pillow — маскот-PNG, Flask — локальный сервер
python3 build/app.py
```
- **Placement-тест** при первом запуске (адаптивный IRT) → стартовый уровень.
- **Уроки** с заданиями (выбор перевода, ввод текста, определения), частичный балл
  для CJK через NFKC + Levenshtein.
- **Живой контент** вместо заглушек: бесплатные API без ключей —
  Tatoeba REST (переводы фраз) и Wiktionary REST (определения). Кэш на 7 дней
  в `~/.threelanguage/content_cache.json`, полная работа офлайн с фолбэком.
- **SRS FSRS-lite**, **АФК-темп-монитор** (засчитывается только реальная работа;
  idle > 25 с вычитается, раздутые замеры заменяются медианой), **оценка урока 0..100**.
- **Прогресс дня** отдельно по каждому языку (минуты идут по «весу» активности,
  не по wall-clock).
- **Настройки**: тема light/dark, сброс скорости, сброс прогресса, выбор языка
  интерфейса и изучаемых языков через сканер папок `lang_packs/`
  (два типа пакетов: `app_ui/*` — язык приложения, `study/*` — язык для изучения,
  формат «из русского в английский», «из русского в китайский»…).
- **Регистрация/вход по паролю** и синхронизация с локальным сервером.
- Состояние: SQLite в `~/.threelanguage/desktop.db` (сброс — удалить файл).

### Локальный сервер (Flask)
```bash
python3 local_server/server.py    # http://127.0.0.1:8765
```
- Auth (pbkdf2), push/pull состояния, статистика.
- **Админ-панель** `/admin`: статистика пользователей, просмотр состояний,
  вставка своих примеров. Вход по паролю из `admin_credentials.json` (корень
  репозитория; дефолт создаётся автоматически — смените его!).
- Защита от «сирот»: если GUI закрылся, сервер завершается сам; stale-lock
  чистится автоматически; при занятом порте выбирается следующий свободный
  (фактический порт пишется в `~/.threelanguage/server_port`).
- GUI умеет поднимать сервер сам при включении синхронизации.

### Ядро и паритет реализаций
Эталон формул — `shared/algorithm/reference.py` (Python). Порты: Kotlin
(`android/core`) и C++ (`desktop/src`). Любая правка формулы: reference.py →
регенерация `fixtures/*.json` → порты. Проверка паритета:
```bash
./tools_ci.sh                     # Python-эталон + C++ golden-тесты
```

### Автотесты UI
```bash
xvfb-run -a python3 build/smoke_test.py   # полный прогон: placement→урок→АФК→sync
```

## Структура репозитория
| Путь | Содержимое |
|---|---|
| `build/` | Desktop-приложение (tkinter): app.py, widgets.py, theme.py, data_sources.py, packs.py, sync_client.py, smoke_test.py |
| `local_server/` | Flask-сервер синхронизации + админка |
| `shared/algorithm/` | Эталонное ядро (SRS, АФК, скоринг, placement) + fixtures |
| `android/`, `desktop/` | Порт-заготовки ядер на Kotlin / C++ |
| `backend/` | FastAPI-скелет будущего облачного бэкенда |
| `assets/mascot/` | PNG-образы дракона (idle/cheer/sad/angry/sleep) + генератор |
| `lang_packs/` | Языковые пакеты (интерфейс и учебные) |
| `docs/` | Спецификации v0.1 (архитектура, SRS, АФК, скоринг, sessions…) |
| `admin_credentials.json` | Логин/пароль админки локального сервера |

## Статус и дорожная карта
- ✅ Desktop (Python/tkinter) — основной тестируемый билд
- ✅ Живые уроки из свободных API + офлайн-кэш
- ✅ Локальный сервер, админка, аккаунты, синхронизация
- 🚧 Веб-версия приложения (HTML+CSS+JS поверх того же ядра) — в разработке
- ⬜ Android Gradle-проект, сборка Qt-десктопа, облачный backend, аудио/говорение

## Правила проекта
1. Формулы меняются только через `reference.py` + fixtures + порты (CI-паритет зелёный).
2. Никаких WebView внутри нативных клиентов.
3. PR-only workflow: main не пушится напрямую, всё через pull request.
